# Registro de decisões

Cada decisão importante tomada com ajuda de IA deve virar um arquivo aqui. Isso serve para duas coisas:

1. O usuário consegue **entender e explicar** por que o projeto ficou assim.
2. Na apresentação, fica claro que a IA foi usada com critério, e não como caixa-preta.

## Como nomear

`NNNN-titulo-curto.md`, em ordem:

- `0001-decisoes-iniciais.md`
- `0002-...`

## O que registrar

Use o modelo `0000-modelo.md`. Preencha:

- contexto;
- opções consideradas;
- decisão;
- justificativa;
- requisito do professor afetado;
- o que foi implementado;
- como foi verificado;
- quem aprovou e quando.

## Regras

- **Nunca** registre token, senha, dado real de aluno ou informação secreta.
- Uma decisão por arquivo (ou um bloco pequeno de decisões iniciais relacionadas).
- Quem escreve é o agente `documentacao`, depois que o usuário aprova.
- Se a decisão mudar depois, não apague o arquivo: acrescente “Revisão” com a nova decisão e a data.
